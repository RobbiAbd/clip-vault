# Icons

Place your application icons here:

- `32x32.png` - 32x32 pixel PNG
- `128x128.png` - 128x128 pixel PNG
- `128x128@2x.png` - 256x256 pixel PNG (2x)
- `icon.icns` - macOS icon (convert from PNG using iconutil)
- `icon.ico` - Windows icon (convert from PNG using ImageMagick or online tools)
- `icon.png` - Base icon for system tray (at least 128x128)

You can generate these from a single high-resolution PNG (at least 512x512) using tools like:
- ImageMagick: `convert icon.png -resize 32x32 32x32.png`
- Online converters: cloudconvert.com, convertio.co
- Icon generators: icon.kitchen, iconsgenerator.com

For now, placeholder icons will be used for development.
